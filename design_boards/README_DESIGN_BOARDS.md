# Design Boards

Les planches design/UI utilisateur sont triées par univers. Le dossier `_incoming` a été supprimé après tri pour éviter les doublons.

## Dossiers

- `castle/`
- `sonic/`
- `streets/`
- `fighter/`
- `outrun/`
- `shinobi/`
- `kombat/`
- `paperboy/`
- `minimap/`

## Convention

Chaque dossier univers peut contenir :

- la planche source ;
- un cadre source `cadre ...png` ;
- un `README.md`.

Les assets runtime sont dans `public/assets/`, pas ici.

## Règle

Les planches servent de source. Ne jamais les afficher brutes dans le gameplay.
