# 04 — Art Bible

## Style global

- 16/32-bit ;
- arcade mobile ;
- lisible ;
- hommage par univers ;
- frame/HUD/transitions riches ;
- grille sobre.

## Interdit

- planche brute dans gameplay ;
- labels de planche visibles ;
- décor détaillé derrière la grille ;
- obstacles trop petits ;
- texte illisible mobile.

## Cellules

- pickup 75–95 % cellule ;
- obstacle 80–95 % cellule ;
- danger très contrasté ;
- pickup plus attractif qu’obstacle.

## Chaque univers doit avoir

- palette ;
- HUD ;
- frame ;
- pickups ;
- obstacles ;
- boss icon ;
- clear/game over style ;
- fallback procédural.
