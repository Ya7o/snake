# 11 — Mobile Iteration Workflow

## Flux de travail

Téléphone / conversation :
- analyse screenshots ;
- création tickets ;
- audit ;
- corrections à demander.

PC / Claude Code :
- appliquer tickets ;
- npm run check ;
- npm run dev ;
- tester via téléphone.

## Après première build

1. Lancer sur téléphone.
2. Faire captures :
   - title ;
   - map ;
   - 2 niveaux normaux ;
   - 2 boss ;
   - game over ;
   - clear.
3. Envoyer captures dans la conversation mobile.
4. Demander :
   - audit conformité ;
   - root cause ;
   - tickets correctifs.
5. Envoyer les tickets au PC.

## Format demande mobile

```text
Analyse ces captures.
Vérifie conformité au projet.
Root cause.
Crée ticket.
Puis si nécessaire : plan et code.
```
