# 03 — Mechanics Bible

## Règle

Chaque univers doit avoir une mécanique distincte, visible et jouable au swipe.

## Univers

### Castle — CastleIllusion
Normal : blink walls / illusion tiles.  
Boss : WitchMirror, faux miroirs et vrai miroir.

### Sonic — RingChains
Normal : collecter des anneaux en chaîne pour bonus/progression.  
Boss : LoopSerpent, trajectoires en boucle/orbite.

### Streets — CrowdBlockers
Normal : foules/blockers temporaires.  
Boss : CrimeLord, zones de pression.

### Fighter — ChargeMove
Normal : charge de direction / mouvement propre.  
Boss : FinalChallenger, rounds courts, fenêtres d’attaque.

### OutRun — LaneDrift
Normal : lanes / drift / checkpoints.  
Boss : TurboRival, dépassement.

### Shinobi — FocusMode
Normal : focus / précision / timing.  
Boss : ShadowNinja, decoys.

### Kombat — FatalZones
Normal : zones fatales télégraphiées.  
Boss : DragonGate, finish window.

### Paperboy — DeliveryTargets
Normal : livraisons à cibles.  
Boss : NeighborhoodChaos, obstacles route mayhem.

## Validation mécanique

Pour chaque mécanique :
- une phrase de règle dans le HUD/intro ;
- feedback clair ;
- pas de hasard injuste ;
- test manuel dédié.
