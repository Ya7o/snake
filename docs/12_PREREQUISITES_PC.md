# 12 — Prérequis PC

## Installer

- Node.js LTS
- Git
- VS Code
- Chrome
- Claude Code ou Codex CLI

## Vérifier

```bash
node -v
npm -v
git --version
```

## Démarrer

```bash
npm install
npm run check
npm run dev
```

## Tester sur téléphone

Même Wi-Fi que le PC.

Vite affiche une URL de type :

```text
http://192.168.x.x:5173/
```

Ouvrir cette URL sur le téléphone.
