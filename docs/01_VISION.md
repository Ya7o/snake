# 01 — Vision

Snake Drive V4 est un Snake mobile rétro façon Mega Drive II / 32-bit.

## Promesse

Un Snake simple, lisible et tactile, enrichi par :
- une world map ;
- 8 univers hommage ;
- 16 niveaux ;
- 8 boss ;
- mécaniques différentes ;
- direction artistique forte ;
- web mobile testable rapidement.

## Plateforme

- web mobile ;
- portrait prioritaire ;
- navigateur sur téléphone ;
- PWA/offline plus tard.

## Univers

1. Castle of Illusion
2. Sonic 2
3. Streets of Rage
4. Street Fighter
5. OutRun
6. Shinobi
7. Mortal Kombat
8. Paperboy

## Règle centrale

Le design sert la lisibilité du Snake.  
Le plateau doit rester propre.
