# 08 — Asset Guide

## Sources

Planches source :
`design_boards/_incoming/`

Tri par univers :
`design_boards/[univers]/`

Assets utilisés :
`public/assets/universes/[univers]/`

## Pipeline

1. Identifier la planche.
2. Associer à un univers.
3. Extraire ou recréer.
4. Créer fallback procédural.
5. Tester mobile.

## Règle

Une planche est une source, pas un écran de jeu.
