TEXTURE FILTER POLICY
Sources:
- src/render/TextureFiltering.ts
- src/render/PickupRenderer.ts
- src/render/ObstacleRenderer.ts

Rules:
- texture keys beginning with rt_ use Phaser.Textures.FilterMode.NEAREST.
- texture keys beginning with openmoji- use Phaser.Textures.FilterMode.LINEAR.
- unknown gameplay texture keys use LINEAR by default.

Affected render paths:
- PickupRenderer.fitImageInCell() now applies applyGameplayTextureFilter().
- ObstacleRenderer.fitImageInCell() now applies applyGameplayTextureFilter().
- Runtime pickups, secondary pickups, obstacles, boss idle sprites, and boss attack sprites loaded as rt_* now render with NEAREST when drawn by those renderers.
- OpenMoji/SVG gameplay icons loaded as openmoji-* keep LINEAR to avoid excessive stair-stepping.

UNCHANGED HIGH-RES BACKGROUND PATHS

- GameScene backgrounds keep their existing image path and are not passed through the gameplay texture filter helper.
- Title, LevelIntro, Clear, GameOver, and WorldMap image paths are not changed.
- WorldMapScene still explicitly uses FilterMode.LINEAR for the map texture.

- OpenMoji SVG rasters and backgrounds should remain smooth.
