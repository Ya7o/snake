==============================================================
MECANIQUE COMMUNE A TOUS LES BOSS
==============================================================

BaseBoss (src/mechanics/bosses/BaseBoss.ts) :
- hp = bossHp de LevelConfig (toujours 3 dans levels.ts)
- phase = maxHp - hp (augmente a chaque hit, 0->1->2)
- hitCooldown = 6 ticks d invincibilite apres chaque hit
- isDefeated() = hp <= 0
- Victoire : isDefeated() -> GameScene.triggerClear()
- Defaite : hitWall | hitSelf | isDangerCell(head)

PICKUP GENERIQUE EN MODE BOSS (critique pour QA) :
Source : GameScene.spawnInitialPickup()
- spawnPickup() appele pour TOUS les boss sauf Sonic/Shinobi/OutRun
  -> un pickup generique apparait sur la grille en boss mode
- spawnNextPickup() re-spawn si moins de 1 pickup sur grille
- Quand collecte : onPickupCollected(cell) appele sur le boss mechanic
  -> BaseBoss ne redefini pas onPickupCollected -> retourne {}
  -> Exception : NeighborhoodChaosBoss.onPickupCollected -> hasPaper=true
- applyMechanicUpdate(mr, defaultScore=1) -> score += 1 invisible
  (HUD boss = HP boss, pas score, donc increment invisible pour le joueur)
- snake.growing += 1 -> le serpent grandit d un segment
- EFFET REEL pour 7/8 boss : croissance serpent uniquement, aucun effet boss
- EFFET REEL pour NeighborhoodChaosBoss : active le mecanisme de livraison

==============================================================
BOSS 1 — WITCH MIRROR (Castle)
==============================================================

Fichier : WitchMirrorBoss.ts
Niveau : castle_boss / La Sorciere au Miroir / speed 180ms/tick

CYCLE ETATS :
idle(8t) -> warning(10t) -> attacking(10t) -> vulnerable(18t) -> moving(4t) -> idle...
Apres hit : hit(6t) -> moving -> idle (nouveaux miroirs)

ENTITES :
- count = 2 + phase miroirs total (phase 0 = 2 miroirs, phase 2 = 4 miroirs)
- 1 seul miroir real, les autres fake

ETAT warning :
- real : idle (visuellement neutre)
- fake : warning (signal avertissement)
- getDangerCells() : vide

ETAT attacking :
- real : idle
- fake : attacking -> getDangerCells() -> letal
- HUD : DANGER

ETAT vulnerable :
- real : vulnerable -> getWeakPoints() -> point faible
- fake : idle
- HUD : FRAPPE
- onWeakPointHit -> registerHit -> hp-1, phase+1 -> nouveaux miroirs

PICKUP GENERIQUE :
- Visuel : icone OpenMoji pickupPrimary (eclat magique)
- Effet collecte : snake +1, score +1 invisible
- Effet boss HP : AUCUN
- Role boss : aucun
- Risque confusion : oui - joueur peut croire que collecter aide a gagner

HUD : ATTENTION / DANGER / FRAPPE / TOUCHE ! / PV BOSS

BOSS 6 — SHADOW NINJA (Shinobi)
==============================================================

Fichier : ShadowNinjaBoss.ts
Niveau : shinobi_boss / Ninja de l Ombre / speed 160ms/tick

STRUCTURE :
- count = 2+phase clones, premier = real
- Real revele toutes les 28 ticks, duree 6 ticks
- real revele -> state: real (weakpoint)
- real cache -> state: shadow (pas danger, mais indistinguable)
- fake clones -> state: shadow -> getDangerCells() -> danger

AMBIGUITE CODE :
- real non-revele et fakes = meme state shadow dans ExtraEntity
- getDangerCells() ne filtre que les non-real -> real cache = pas danger
- mais le joueur ne peut pas distinguer visuellelment real cache vs fake

PICKUP GENERIQUE :
- Visuel : assets/universes/shinobi/pickup_01.png
- 3 types a l ecran : shadow (danger), real revele (weakpoint), pickup (inutile en boss)
- Effet collecte : snake +1, score +1 invisible
- Effet boss HP : AUCUN
- Surcharge visuelle : notable

HUD : FRAPPE (real revele) | OBSERVE (sinon)

BOSS 8 — NEIGHBORHOOD CHAOS (Paperboy)
==============================================================

Fichier : NeighborhoodChaosBoss.ts
Niveau : paperboy_boss / Chaos du Quartier / speed 155ms/tick

STRUCTURE (3 vagues) :
- wave 0 : 2 obstacles; wave 1 : 3; wave 2 : 4 (speed 3+wave)
- 2 bossTargets par vague

MECANISME PAPER :
1. Collect pickup generique -> onPickupCollected intercepte -> hasPaper=true
2. HUD : LIVRE
3. bossTargets -> state: highlighted -> glow jaune fort (drawPaperboyTargetGlow)
4. Toucher bossTarget (weakpoint) -> livraison -> hasPaper=false
5. 2 livraisons -> boss.registerHit() -> hp-1

ENTITES :
- type chaosObstacle state: moving -> danger (letal)
- type bossTarget state: idle | highlighted (weakpoint si hasPaper)

PICKUP GENERIQUE :
- Role : LE JOURNAL — SEUL CAS ou pickup boss a un role reel
- Effet collecte : hasPaper=true -> active cibles highlighted
- Effet boss HP : INDIRECT (necessaire pour livrer)
- Comprehension joueur : BONNE avec HUD + glows + theme Paperboy coherent

HUD : LIVRE (hasPaper) | VAGUE 1/3 | VAGUE 2/3 | VAGUE 3/3
