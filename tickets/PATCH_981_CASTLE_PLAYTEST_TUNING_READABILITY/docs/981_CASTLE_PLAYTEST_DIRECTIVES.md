# 981 — Castle Playtest Directives

## Roadmap status

```txt
Phase 2 — Vertical Slice
Patch 980: Castle exists
Patch 981: Castle must become readable and testable
```

---

# Product intent

Do not chase polish everywhere.

Focus on one question:

```txt
Can a new player understand and enjoy Castle without the developer explaining it?
```

If not, fix readability before adding content.

---

# What to optimize

Optimize:
- clarity,
- fairness,
- reaction time,
- boss comprehension,
- feedback.

Do not optimize:
- number of features,
- asset count,
- all-world balance,
- cinematic spectacle.

---

# Main player questions

The game must answer these visually:

```txt
What should I collect?
What is dangerous?
When is it dangerous?
What changed after I cleared the stage?
How do I damage the boss?
```

If the player has to guess, the patch is incomplete.

---

# Priority order

If time is limited:

1. Warning wall readability.
2. Active danger clarity.
3. Boss weak-point clarity.
4. Boss hit feedback.
5. Death/clear feedback.
6. QA/playtest docs.

Do not spend time polishing menus unrelated to Castle flow.
