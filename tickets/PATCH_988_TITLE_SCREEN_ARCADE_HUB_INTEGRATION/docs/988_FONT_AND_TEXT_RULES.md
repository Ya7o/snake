# 988 — Font And Text Rules

## Title

Use a strong pixel display style.

Text:
```txt
SNAKE DRIVE
```

Recommended:
- large but not oversized;
- green/yellow fill;
- violet/cyan drop shadow;
- 1–2 px outline equivalent.

---

# Stats

Text:
```txt
8 MONDES · 16 NIVEAUX
8 BOSS À DÉBLOQUER
```

Recommended:
- smaller than title;
- warm white or pale gray;
- slight shadow.

---

# CTA

Text:
```txt
TOUCHER POUR JOUER
```

Recommended:
- gold or pale yellow;
- clear button contrast;
- uppercase;
- readable at mobile size.

---

# Do not use `V4`

Do not present:
```txt
DRIVE V4
```

as the main brand.

It makes the game look like a dev build rather than a product.

If a version is needed, use tiny footer:
```txt
PROTOTYPE BUILD
```
or omit entirely.
