# Castle Generation Prompts

These are the prompts used or closely approximated for the validated Castle asset set.

The important part is not the exact wording, but the doctrine:
- background only,
- no text,
- no buttons,
- no HUD,
- runtime owns UI.

---

# 1. castle_system_bg.png

```txt
Crée un background vertical 9:16 pour un jeu mobile fantasy rétro inspiré d’un château féerique.
Usage : écran système / intro / menu d’univers.

Image de fond uniquement, sans texte, sans boutons, sans HUD, sans score, sans panneaux UI.
L’ambiance doit montrer un château magique, une forêt enchantée, une lune brillante, quelques lanternes et lueurs féeriques.
Le centre doit rester assez calme et lisible pour accueillir un panel runtime avec texte et boutons.
Style pixel-inspired 16/32-bit, nostalgique, lisible sur téléphone.
```

---

# 2. castle_gameplay_bg.png

```txt
Crée un background vertical 9:16 pour un écran de gameplay Snake mobile fantasy rétro inspiré d’un château féerique.

Image de décor uniquement, sans texte, sans boutons, sans HUD, sans score, sans cadre UI.
Le centre doit rester très sobre et peu détaillé pour accueillir une grille de gameplay.
Le décor doit se concentrer surtout sur les bords et le bas : pierre de château, forêt enchantée, lanternes, touches de magie, nuit bleue-violette.
Style pixel-inspired 16/32-bit, très lisible sur téléphone.
```

---

# 3. castle_game_over_bg.png

```txt
Crée un background vertical 9:16 pour un écran Game Over dans un univers de château féerique rétro.

Image de fond uniquement, sans texte, sans boutons, sans HUD, sans score.
Ambiance plus sombre, plus silencieuse, plus inquiétante : château lointain, lune froide, forêt obscure, magie troublée, lanternes faibles.
Le centre doit rester exploitable pour poser un message de défaite et des boutons runtime.
Style pixel-inspired 16/32-bit, lisible sur téléphone.
```

---

# 4. castle_clear_bg.png

```txt
Crée un background vertical 9:16 pour un écran de victoire / stage clear dans un univers de château féerique rétro.

Image de fond uniquement, sans texte, sans boutons, sans HUD, sans score.
Ambiance lumineuse, magique, gratifiante : château illuminé, ciel plus chaud, lueurs dorées, étoiles et particules féeriques.
Le centre doit rester assez lisible pour accueillir un message de succès et des boutons runtime.
Style pixel-inspired 16/32-bit, nostalgique et lisible sur téléphone.
```
