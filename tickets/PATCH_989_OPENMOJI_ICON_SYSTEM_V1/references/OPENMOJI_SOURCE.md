# OpenMoji Source Reference

Repository:

```txt
https://github.com/hfg-gmuend/openmoji
```

Recommended temporary clone:

```bash
git clone --depth 1 https://github.com/hfg-gmuend/openmoji.git /tmp/openmoji
```

Release reference:

```txt
https://github.com/hfg-gmuend/openmoji/releases/tag/17.0.0
```

Relevant notes from the official repository:
- repository contains exported PNG/SVG files;
- stable production use should prefer releases;
- shallow clone is recommended because the repo is large;
- attribution is requested;
- suggested license attribution mentions CC BY-SA 4.0.
