# 989 — License / Attribution

## Required attribution

Add this attribution to README, docs, or About/Credits screen:

```txt
Selected emoji/icon assets by OpenMoji — the open-source emoji and icon project.
License: CC BY-SA 4.0.
https://openmoji.org/
```

---

# Where to place attribution

Preferred:

```txt
docs/CREDITS.md
README.md
```

If the game has an About screen later, add it there too.
