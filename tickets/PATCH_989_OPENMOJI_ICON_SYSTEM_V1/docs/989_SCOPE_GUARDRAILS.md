# 989 — Scope Guardrails

## In scope

- fetch/copy selected OpenMoji icons,
- icon registry,
- title/world/HUD small icon usage,
- attribution,
- documentation.

---

# Out of scope

- replacing backgrounds,
- replacing main sprites,
- replacing boss sprites,
- redesigning screens,
- adding new UI flow,
- adding dependencies unnecessarily,
- committing full OpenMoji repo.

---

# Do not overuse OpenMoji

OpenMoji is a V1 simplification tool, not the whole art direction.

Use it for small icons only.
