# AUDIT 957 — Accessibilité / confort

## Constats
- Contraste / lisibilité : 248
- Motion / blink / tween : 422
- Audio / mute : 47
- Couleurs danger/success : 311

## Risques
- P1 : danger uniquement par couleur.
- P1 : clignotements fatigants.
- P2 : texte trop petit sur mobile.
- P2 : absence mute si audio actif.

## Corrections recommandées
- Vérifier contraste de tous les textes visibles.
- Ne pas transmettre danger uniquement par couleur.
- Limiter clignotements / flashs.
- Ajouter ou vérifier mute si audio actif.
- Vérifier confort après 10 minutes de jeu.
