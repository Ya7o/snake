# 987 — Gameplay Board Framing Guidelines

## Goal

Make the board more comfortable visually while preserving gameplay readability.

## Recommended direction

### Board width
Target board width:
```txt
78% to 84% of the available screen width
```

### Board height
Target board height:
```txt
58% to 68% of the available screen height
```

### Board placement
Recommended conceptual split:

```txt
Top info zone:      8%–12%
Gap zone:           2%–3%
Board zone:         58%–68%
Bottom décor zone:  15%–22%
```

### Cell size
Correct approach:
- reduce cell size moderately;
- keep grid line readability;
- keep snake readable;
- use the saved space to reveal more of the image.

Recommended action:
```txt
Reduce effective cell size by around 8% to 14%
```

## Final recommendation

Use this target first:

```txt
board width: 82%
board height: 63%
top info zone: 10%
gap below HUD: 2%
bottom reveal: 18%
```
