# 987 — Visual System Rules For Castle

## Rule 1 — Background first, UI second
The background image is part of the experience, not a hidden backing.

## Rule 2 — Runtime overlays must be light
Use smaller panels, smaller HUD modules, and deliberate spacing.

## Rule 3 — Gameplay board is a framed window
The board must leave room for the world around it.

## Rule 4 — One visual hierarchy
Castle should read like this:

```txt
Background atmosphere
Primary gameplay or result headline
Primary action button
Secondary action button
Support text
```

## Rule 5 — Typography must separate roles
Universe title ≠ HUD label ≠ body text ≠ button label

## Rule 6 — Reusability matters
The HUD solution chosen for Castle should be reusable for the other 7 universes with palette/icon/title swaps.
