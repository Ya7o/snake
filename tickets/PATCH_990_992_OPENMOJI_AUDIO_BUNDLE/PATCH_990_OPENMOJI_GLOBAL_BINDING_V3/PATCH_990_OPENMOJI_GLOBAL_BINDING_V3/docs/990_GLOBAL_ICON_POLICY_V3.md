# 990 V3 — Global Icon Policy

## Core rule

```txt
OpenMoji is for small V1 functional icons.
OpenMoji is not the visual identity of the whole game.
```

---

# Use OpenMoji for

```txt
world tokens
world selection icons
HUD micro-icons
pickup placeholders
obstacle placeholders
danger/hazard markers
boss-event markers
result screen symbols
lock/unlock
pause/play/home controls
key/shield/bonus quick wins
```

---

# Do not use OpenMoji for

```txt
backgrounds
title background
main Snake sprite
boss character sprites
gameplay board
gameplay grid
large decorative panels
primary logo
```

---

# Castle V1 quick-win set

```txt
🏰 world
✨ magic pickup
💎 bonus gem
🔮 orb / portal
🗝️ key / unlock
🛡️ shield
🌟 bonus / perfect
🧱 wall obstacle
🪨 stone obstacle
🚪 door/gate
🔥 danger
⚠️ warning
💀 boss/death
👑 boss reward
🏆 clear
🚩 stage
⏸️ pause
▶️ play
🏠 home
```

This is enough. Do not keep adding icons unless a real mechanic requires it.
